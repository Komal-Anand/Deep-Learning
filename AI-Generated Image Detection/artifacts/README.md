# Model Artifacts Directory

This folder contains serializations and training histories generated by the deep learning training pipelines.

---

## Stored Artifacts

1. **`best_efficientnet_b0.pth`**
   - Checkpoint containing PyTorch state dictionary for the top-performing EfficientNet-B0 transfer learning model.
   - Saved automatically by `training/train_efficientnet.py` whenever validation loss improves.

2. **`best_custom_cnn.pth`**
   - Checkpoint containing PyTorch state dictionary for the baseline 4-block Convolutional Neural Network.
   - Saved automatically by `training/train_cnn.py`.

3. **`efficientnet_training_history.json`**
   - Epoch-by-epoch loss, accuracy, and stage tracking (Head warmup vs Fine-tuning) for EfficientNet-B0.

4. **`cnn_training_history.json`**
   - Epoch-by-epoch loss, accuracy, and learning rate tracking for Custom CNN.

---

*Note: Model checkpoint binary files (.pth) are excluded from Git source control to keep repository footprints lightweight.*
