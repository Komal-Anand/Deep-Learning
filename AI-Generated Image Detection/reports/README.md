# Evaluation Reports & Research Visualizations

This directory stores quantitative performance evaluations and publication-ready figures generated by `training/evaluate.py`.

---

## Generated Deliverables

1. **`evaluation_metrics.json`**
   - High-precision JSON summary containing held-out test set accuracy, precision, recall, F1-scores, ROC-AUC values, and robustness scores.

2. **Visualizations**:
   - `efficientnet-b0_confusion_matrix.png` & `custom_cnn_confusion_matrix.png`: Normalized confusion matrix heatmaps showing true vs predicted class distributions.
   - `efficientnet-b0_roc_curve.png` & `custom_cnn_roc_curve.png`: Receiver Operating Characteristic curves displaying True Positive Rate vs False Positive Rate and AUC scores.
   - `efficientnet-b0_training_curves.png` & `custom_cnn_training_curves.png`: Training and validation loss and accuracy trajectories over epochs.
   - `model_comparison_chart.png`: Comparative bar chart contrasting Baseline CNN vs EfficientNet-B0.
   - `efficientnet-b0_robustness_chart.png`: Classification stability under JPEG compression (Q=50), Gaussian blur (r=2.0), and downscaling (0.5x).

---

*All metrics are calculated strictly on actual model predictions; no synthetic or placeholder metrics are permitted.*
