# Dataset Directory Guide: AI-Generated Image Detection

This directory organizes raw and preprocessed images used for training, validating, and testing the deep learning models.

---

## 1. Supported Public Research Datasets

### A. GenImage Benchmark (Recommended for Large-Scale Research)
- **Paper**: Zhu et al., *"GenImage: A Million-Scale Benchmark for Detecting AI-Generated Images"*, NeurIPS 2023.
- **Content**: 1,331,167 images spanning 8 leading generative architectures:
  - Stable Diffusion v1.4 & v1.5
  - Midjourney v5
  - GLIDE
  - VQDM
  - BigGAN
  - ADM (Ablated Diffusion Models)
  - Wukong
- **Access**: [GenImage GitHub Repository](https://github.com/GenImage-Dataset/GenImage)

### B. CIFAKE Dataset (Recommended for Fast Local Experimentation)
- **Paper**: Bird & Lotfi, *"CIFAKE: A Dataset for Detecting AI-Generated Synthetic Images"*, Data in Brief 2023.
- **Content**: 120,000 images (60,000 real CIFAR-10 photos and 60,000 synthetically generated equivalents via Stable Diffusion v1.4).
- **Access**: [Kaggle CIFAKE Dataset](https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images)

## 2. Directory Layout

Place your raw downloaded images into the following folder structure:

```
data/
├── real/
│   ├── photo_0001.jpg
│   ├── photo_0002.png
│   └── ...
├── ai_generated/
│   ├── synth_0001.jpg
│   ├── synth_0002.png
│   └── ...
└── splits/           # Automatically generated by training/prepare_data.py
    ├── train/
    │   ├── Real/
    │   └── AI-Generated/
    ├── val/
    │   ├── Real/
    │   └── AI-Generated/
    ├── test/
    │   ├── Real/
    │   └── AI-Generated/
    └── dataset_manifest.json
```

## 3. Data Preparation Workflow

Run the data preparation script:

```bash
python training/prepare_data.py
```

### What this script performs:
1. **File Integrity Verification**: Uses Pillow decoding to detect corrupted or unreadable images.
2. **Cryptographic Deduplication**: Calculates SHA-256 digests for all images. Exact and duplicate copies are removed to strictly prevent **data leakage** across splits.
3. **Stratified Splitting**: Automatically splits images into:
   - **70% Training**
   - **15% Validation**
   - **15% Held-Out Testing**
4. **Starter Demo Mode**: If `data/real/` and `data/ai_generated/` are empty, the script automatically generates structured photographic and synthetic test samples so the pipeline can be demonstrated immediately without multi-gigabyte downloads.
